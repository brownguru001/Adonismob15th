# Typography

No files needed here — the two brand typefaces are loaded live as Google
Fonts via `next/font/google` in `src/app/layout.tsx`:

- **Display: Cinzel** (weights 500/600/700/900)
- **Body: Libre Franklin**

See `.claude/skills/adonis-designer/BRAND_SYSTEM.md` → "Typography" for
usage rules. When designing outside the codebase (an exported PNG/PDF),
load the same two fonts by name from Google Fonts rather than substituting
a similar-looking typeface.

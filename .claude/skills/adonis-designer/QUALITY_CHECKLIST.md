# ADONISMOB15TH — Quality Checklist

Run this before presenting any design as finished. If any answer is no,
revise before presenting — don't present a draft as a final and let the
user find the problem.

- **Brand** — Does this immediately look like ADONISMOB15TH, specifically
  (not "a dark luxury brand" generically)? Check: Cinzel used correctly,
  the exact wordmark pattern, gold used once with intent, no second accent
  color introduced.
- **Product** — If a product is shown: is it clearly visible, unaltered,
  and accurately represented? No invented logo, embroidery, or detail that
  wasn't in the supplied photo.
- **Typography** — Is the hierarchy actually a hierarchy (one clear primary
  element), not several competing headlines?
- **Composition** — Does the eye know where to look first, with no
  guidance needed?
- **Spacing** — Does the design breathe? If it feels tight, it needs more
  negative space, not smaller type.
- **Premium feel** — Does it look expensive because of restraint and
  craft, or does it look expensive because gold/shadows/effects were piled
  on? Only the first answer passes.
- **Consistency** — Does this fit next to the live site and past approved
  designs in `assets/adonis/approved-designs/` without looking like a
  different brand made it?
- **Commercial value** — Would this actually make someone want the piece,
  not just recognize the brand?

## Product/brand integrity gate (hard stop, not a judgment call)

Before anything else, confirm none of these happened — if any did, the
design is not "revise," it's "start over":

- The clothing design, logo, or proportions were altered.
- A detail (embroidery, brand mark) was invented that wasn't supplied.
- The rose asset was replaced with something generated or unrelated.
- A new logo/wordmark variant was invented instead of using the real one.
- An unrelated symbol was introduced.

## The rose — exact paths

- Color: `public/rose/color/frame-001.webp` … `frame-080.webp`
- Line: `public/rose/line/frame-001.webp` … `frame-080.webp`

These are real traced frames from an actual rotating reference video, used
live on-site as a scroll-scrubbed turntable (`src/components/rose-sequence.tsx`).
For a static design, pick one frame — a three-quarter angle in the
`015–025` or `055–065` range of either set reads best still. Never
regenerate or substitute a different rose.

## Saving an approved design

Once a design produced by this skill is actually approved (not just
drafted), save the exported file into `assets/adonis/approved-designs/`
with a name that says what it is and when: `2026-08-drop-preset04-tee.png`,
not `final_v3_FINAL.png`. This folder is also the closest thing to a
"study the existing designs" archive going forward — it starts empty
today and becomes the real reference material over time.

## Social & marketing format specifications

| Format | Dimensions | Notes |
| --- | --- | --- |
| Instagram portrait | 1080 × 1350 | Safe margin: keep text 80px+ from every edge |
| Instagram square | 1080 × 1080 | |
| Instagram / Facebook Story | 1080 × 1920 | Keep the center-safe zone (avoid top/bottom ~250px — UI overlays) |
| TikTok / Reels | 1080 × 1920 | Same center-safe-zone rule as Stories |
| Facebook post | 1200 × 630 | Wide format — favor horizontal composition |
| Website product banner | 1600 × 600 (adjust to the actual slot) | Match the live site's existing banner aspect before finalizing |
| Website product card | 800 × 1000 (portrait, matches garment proportions) | |
| Clothing catalogue page | A4 or Letter, print-safe margins (0.5in) | Multi-product grid — see Preset 08 for how to keep a grid from looking generic |
| Promotional flyer | A5 or A4, print-safe margins (0.5in) | |

Always preserve safe margins and legible type at the format's actual
display size — check a design at real scale (thumbnail-sized for social),
not only zoomed in while designing it.

## Design tooling in practice

No Canva integration exists. Output is produced as an HTML/CSS composition
— real Google Fonts (Cinzel, Libre Franklin), the real hex values above,
the real rose asset or a real supplied product photo — rendered to PNG or
PDF via a headless-browser export. This is the same pipeline already used
for every other visual document produced in this project; it is a working
tool, not a stand-in for one that doesn't exist.
